# 🎬 ReelsScript Bot - Генератор сценариев для рилсов

Telegram-бот для генерации сценариев для рилсов, TikTok и YouTube Shorts с помощью AI.

## 🚀 Возможности

- ✨ Генерация уникальных сценариев для коротких видео
- 🎯 Поддержка разных ниш (юмор, лайфхаки, мотивация, обзоры, образование)
- ⏱️ Разные форматы (15 сек, 30 сек, 60 сек, longform)
- 🎨 Различные стили (динамичный, спокойный, драматичный, образовательный)
- 📝 Визуальные подсказки и рекомендации по хэштегам
- 🤖 Поддержка нескольких AI провайдеров (Groq, OpenAI, YandexGPT)

## 📋 Требования

- Python 3.8+
- Telegram Bot Token (получите у [@BotFather](https://t.me/BotFather))
- API ключ от одного из провайдеров (см. ниже)

## 🆓 Бесплатные AI провайдеры

Бот поддерживает несколько провайдеров, включая бесплатные:

### 1. **YandexGPT (Рекомендуется - БЕСПЛАТНЫЙ ТАРИФ!)**
- ✅ Есть бесплатный тариф для тестирования
- ✅ Отлично работает с русским языком
- ✅ Удобно для пользователей из России/СНГ
- 🔗 Получить ключ: https://yandex.cloud/ru/docs/foundation-models/operations/create-api-key
- ⚠️ Требуется создать каталог в Yandex Cloud (это бесплатно)

### 2. **Groq (БЕСПЛАТНО!)**
- ✅ Полностью бесплатный
- ✅ Очень быстрый
- ✅ Хорошее качество генерации
- 🔗 Получить ключ: https://console.groq.com/keys
- 📖 Документация: https://console.groq.com/docs

### 3. **OpenAI (Платный)**
- 💰 Требует пополнения баланса
- ✅ Лучшее качество (GPT-4)
- 🔗 Получить ключ: https://platform.openai.com/api-keys

## 🔧 Установка

1. **Клонируйте репозиторий или скачайте файлы**

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создайте файл `.env` на основе `.env.example`**

4. **Заполните `.env` файл:**

   **Для YandexGPT (бесплатный тариф, рекомендуется):**
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   AI_PROVIDER=yandexgpt
   YANDEX_API_KEY=ваш_yandex_api_ключ
   YANDEX_FOLDER_ID=ваш_folder_id
   YANDEX_MODEL=yandexgpt/latest
   ```
   
   **Для Groq (бесплатно):**
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   AI_PROVIDER=groq
   GROQ_API_KEY=ваш_groq_api_ключ
   GROQ_MODEL=llama-3.1-70b-versatile
   ```
   
   **Для OpenAI (платно):**
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   AI_PROVIDER=openai
   OPENAI_API_KEY=ваш_openai_api_ключ
   OPENAI_MODEL=gpt-4o-mini
   ```

## 🎮 Запуск

```bash
python bot.py
```

## 📖 Использование

1. Найдите вашего бота в Telegram
2. Отправьте команду `/start`
3. Нажмите "🎬 Создать сценарий"
4. Выберите параметры:
   - Ниша контента
   - Формат видео
   - Стиль сценария
   - (Опционально) Тему для сценария
5. Получите готовый сценарий!

## 💡 Команды бота

### Для пользователей:
- `/start` - Начать работу с ботом
- `/help` - Показать справку
- `/new` - Создать новый сценарий
- `/support` - Связаться с поддержкой
- `/subscribe` - Информация о подписке

### Для разработчиков (из DEVELOPER_USER_IDS):
- `/admin` - Список всех административных команд
- `/reply <user_id> <сообщение>` - Ответить пользователю напрямую
- `/give_sub <user_id> [days]` - Выдать подписку пользователю
- `/remove_sub <user_id>` - Удалить подписку пользователя
- `/user_info <user_id>` - Информация о пользователе
- `/stats` - Статистика бота
- `/reset_user <user_id>` - Сбросить лимиты пользователя
- `/broadcast <сообщение>` - Рассылка всем пользователям
- Ответ на пересланное сообщение - автоматически отправляется пользователю

## 🎯 Новые возможности

- ✨ **Развитие идей** - после генерации сценария можно доработать его (сделать более динамичным, добавить юмор и т.д.)
- 📊 **Система лимитов** - контроль количества запросов на пользователя (по умолчанию 10)
- 👨‍💻 **Whitelist для разработчиков** - безлимитный доступ для тестирования
- 💎 **Премиум подписка** - безлимитное количество запросов за оплату
- 💬 **Система поддержки** - пользователи могут обращаться в поддержку, разработчики могут отвечать

## ⚙️ Настройка лимитов, whitelist и подписок

В файле `.env` можно настроить:

```env
# Лимит запросов на пользователя (по умолчанию 10)
MAX_REQUESTS_PER_USER=10

# Whitelist для разработчиков (безлимит) - через запятую
# Чтобы узнать свой user_id, напишите боту @userinfobot в Telegram
DEVELOPER_USER_IDS=123456789,987654321

# Настройки подписок (Telegram Payments)
# Получите токен у @BotFather после настройки платежей
PAYMENT_PROVIDER_TOKEN=ваш_payment_provider_token
# Цена подписки в копейках (29900 = 299 рублей)
SUBSCRIPTION_PRICE=29900
# Длительность подписки в днях
SUBSCRIPTION_DURATION_DAYS=30
```

## 💎 Система подписок

Бот поддерживает два тарифа:

### Бесплатный тариф
- ✅ 10 запросов (настраивается в `.env`)
- ✅ Все основные функции
- ⚠️ Лимит сбрасывается при перезапуске бота

### Премиум подписка
- 💎 Безлимитное количество запросов
- ⚡ Приоритетная обработка
- 🎯 Доступ ко всем функциям
- 💬 Приоритетная поддержка
- 📅 Действует 30 дней (настраивается)

### Как настроить платежи

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/mybots`
3. Выберите вашего бота
4. Выберите "Bot Settings" → "Payments"
5. Настройте платежи (выберите провайдера)
6. Получите `PAYMENT_PROVIDER_TOKEN`
7. Добавьте токен в файл `.env`

**Примечание:** Для тестирования можно использовать тестовый режим платежей.

## 💬 Система поддержки

Бот поддерживает двустороннюю связь между пользователями и поддержкой.

### Для пользователей:

1. Нажмите кнопку "💬 Поддержка" или отправьте команду `/support`
2. Опишите вашу проблему или вопрос
3. Сообщение будет отправлено всем разработчикам из `DEVELOPER_USER_IDS`
4. Вы получите ответ в течение нескольких часов

### Для разработчиков:

Разработчики (пользователи из `DEVELOPER_USER_IDS`) могут отвечать пользователям двумя способами:

1. **Через reply на пересланное сообщение:**
   - Когда пользователь пишет в поддержку, его сообщение пересылается разработчикам
   - Просто ответьте на пересланное сообщение - ответ автоматически отправится пользователю

2. **Через команду `/reply`:**
   - Использование: `/reply <user_id> <сообщение>`
   - Пример: `/reply 123456789 Привет! Мы исправили проблему.`

**Важно:** Убедитесь, что ваш `user_id` добавлен в `DEVELOPER_USER_IDS` в файле `.env`.

## 🎯 Как получить YandexGPT API ключ (бесплатно)

1. Перейдите на https://console.groq.com/
2. Зарегистрируйтесь (можно через Google/GitHub)
3. Перейдите в раздел "API Keys"
4. Создайте новый ключ
5. Скопируйте ключ в файл `.env`

Готово! Теперь бот работает бесплатно! 🎉
