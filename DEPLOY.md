# 🚀 Деплой бота на Amvera

## Шаг 1: Выбор типа сервиса

**Выберите: "Приложения" (Applications)**

Это правильный выбор, потому что:
- Telegram бот - это долгоживущий процесс
- Он должен постоянно работать и обрабатывать обновления
- Это не база данных, не cron job и не готовое приложение из маркетплейса

## Шаг 2: Подготовка проекта

### 2.1. Убедитесь, что все файлы на месте:

```
telegram-bots/
├── bot.py
├── config.py
├── requirements.txt
├── amvera.yaml          # Конфигурация для Amvera
├── services/
│   ├── __init__.py
│   ├── scenario_generator.py
│   ├── limits_manager.py
│   └── subscription_manager.py
└── .env                 # НЕ загружайте в Git! (уже в .gitignore)
```

### 2.2. Проверьте requirements.txt

Убедитесь, что все зависимости указаны:
```
aiogram==3.4.1
python-dotenv==1.0.0
openai==1.12.0
aiohttp==3.9.3
requests==2.31.0
```

## Шаг 3: Деплой на Amvera

### 3.1. Создайте проект в Amvera

1. Зайдите на [Amvera](https://amvera.io)
2. Нажмите "Создать проект"
3. Выберите тип: **"Приложения" (Applications)**
4. Выберите язык: **Python 3.11** (или последняя версия)

### 3.2. Подключите репозиторий

**Вариант A: Через Git (рекомендуется)**

1. Создайте репозиторий на GitHub/GitLab
2. Загрузите код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin <ваш_репозиторий>
   git push -u origin main
   ```
3. В Amvera подключите репозиторий через Git

**Вариант B: Прямая загрузка**

1. В Amvera выберите "Загрузить код"
2. Загрузите все файлы проекта (кроме `.env`)

### 3.3. Настройте переменные окружения

В панели Amvera перейдите в раздел "Переменные окружения" и добавьте:

**Обязательные:**
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
AI_PROVIDER=yandexgpt
```

**Для YandexGPT:**
```
YANDEX_API_KEY=ваш_yandex_api_ключ
YANDEX_FOLDER_ID=ваш_folder_id
YANDEX_MODEL=yandexgpt/latest
```

**Для Groq (альтернатива):**
```
AI_PROVIDER=groq
GROQ_API_KEY=ваш_groq_api_ключ
GROQ_MODEL=llama-3.1-70b-versatile
```

**Для OpenAI (альтернатива):**
```
AI_PROVIDER=openai
OPENAI_API_KEY=ваш_openai_api_ключ
OPENAI_MODEL=gpt-4o-mini
```

**Опциональные настройки:**
```
MAX_REQUESTS_PER_USER=10
DEVELOPER_USER_IDS=5620602187
PAYMENT_PROVIDER_TOKEN=ваш_payment_provider_token
SUBSCRIPTION_PRICE=29900
SUBSCRIPTION_DURATION_DAYS=30
```

### 3.4. Настройте запуск

В настройках приложения укажите:
- **Команда запуска:** `python bot.py`
- **Порт:** Amvera автоматически определит (для Telegram бота не важен)
- **Рабочая директория:** `/` (корень проекта)

### 3.5. Деплой

1. Нажмите "Деплой" или "Deploy"
2. Дождитесь завершения сборки
3. Проверьте логи на наличие ошибок

## Шаг 4: Проверка работы

1. Откройте логи в панели Amvera
2. Убедитесь, что видите: `Запуск бота...`
3. Проверьте, что нет ошибок
4. Напишите боту в Telegram - он должен ответить

## Шаг 5: Мониторинг

- **Логи:** Смотрите в реальном времени в панели Amvera
- **Статистика:** Используйте команду `/stats` в боте
- **Перезапуск:** Если нужно, используйте кнопку "Перезапустить" в панели

## ⚠️ Важные замечания

1. **Не загружайте `.env` в Git!** - он уже в `.gitignore`
2. **Все секретные данные** должны быть в переменных окружения Amvera
3. **База данных SQLite** сохраняется в постоянное хранилище `/data/bot_database.db` на Amvera. Данные сохраняются между перезапусками.
4. **MemoryStorage (FSM)** - состояния диалогов теряются при перезапуске. Для production можно использовать Redis, но для большинства случаев текущая реализация достаточна.
5. **Логи** - проверяйте регулярно на наличие ошибок

## 🔧 Решение проблем

### Бот не запускается
- Проверьте логи в Amvera
- Убедитесь, что все переменные окружения установлены
- Проверьте, что `TELEGRAM_BOT_TOKEN` правильный

### Ошибки импорта
- Убедитесь, что `requirements.txt` содержит все зависимости
- Проверьте, что версия Python правильная (3.11)

### Бот не отвечает
- Проверьте логи на наличие ошибок
- Убедитесь, что бот запущен (статус в панели Amvera)
- Проверьте токен бота
